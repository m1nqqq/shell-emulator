# Эмулятор оболочки ОС

Консольный эмулятор UNIX-подобной командной строки на Python.
Внешние зависимости не требуются, используется только стандартная
библиотека (Python 3.9+).

## Общее описание

Эмулятор ведёт диалог с пользователем в стиле командной строки
UNIX-подобной ОС: показывает приглашение, разбирает ввод и выполняет
команды. Поведение настраивается параметрами командной строки, а набор
команд выполняется как в интерактивном режиме, так и из стартового
скрипта.

Реализовано (этапы 1–2): REPL, параметры командной строки, стартовый
скрипт, отладочный вывод параметров, команды-заглушки `ls`, `cd` и `exit`.

## Функции и настройки

### Приглашение к вводу

Формируется из реальных данных ОС: `username@hostname:~$`
(`getpass.getuser()` и `socket.gethostname()`).

### Параметры командной строки

| Параметр        | Описание                                  |
|-----------------|-------------------------------------------|
| `--vfs PATH`    | Путь к физическому расположению VFS       |
| `--script PATH` | Путь к стартовому скрипту                 |
| `-h`, `--help`  | Справка                                   |

Оба параметра необязательны. При запуске эмулятор выводит все заданные
параметры в формате «ключ = значение» (строки с префиксом `[debug]`);
незаданный параметр показывается как `<not set>`.

Коды завершения: `0` — штатное завершение, `1` — не удалось прочитать
стартовый скрипт, `2` — неверные параметры командной строки.

### Стартовый скрипт

Текстовый файл в кодировке UTF-8, по одной команде эмулятора в строке.

- Строка, начинающаяся с `#`, — комментарий. Комментарий может стоять и
  в конце строки после команды: `cd docs  # перейти`.
- Пустые строки пропускаются.
- Каждая команда показывается на экране после приглашения, затем её
  вывод — как в настоящем диалоге с пользователем.
- Если команда завершилась ошибкой, выводится сообщение команды и строка
  `script error: line N: command failed`; выполнение скрипта продолжается.
- Команда `exit` завершает работу эмулятора (остаток скрипта
  не выполняется). Если скрипт закончился без `exit`, эмулятор переходит
  в интерактивный режим.
- Если файл скрипта не найден или не читается, выводится
  `error: cannot read startup script ...` и эмулятор завершается с кодом 1.

### Команды

| Команда | Описание                                           |
|---------|----------------------------------------------------|
| `ls`    | Заглушка: выводит своё имя и аргументы             |
| `cd`    | Заглушка: выводит своё имя и аргументы             |
| `exit`  | Завершает работу эмулятора                         |

Неизвестная команда: `unknown command: <имя>`. Ctrl+C отменяет ввод
строки, Ctrl+D (Ctrl+Z и Enter в Windows) завершает работу.

## Структура репозитория

```
src/            исходный код (main.py, shell.py, commands.py)
tests/          автоматические тесты (unittest)
scripts/        скрипты реальной ОС для проверки эмулятора (.bat)
scripts/startup/ стартовые скрипты эмулятора
scripts/vfs/    файлы VFS для проверок
run.bat, run.sh скрипты запуска эмулятора
```

## Сборка и запуск тестов

Сборка не требуется. Запуск автоматических тестов (из корня проекта):

```
python -m unittest discover -s tests
```

Скрипты реальной ОС (Windows) для проверки параметров командной строки:

```
scripts\test_stage2_basic.bat
scripts\test_stage2_paths.bat
scripts\test_stage2_errors.bat
```

## Запуск

```
run.bat                    # Windows
./run.sh                   # Linux / macOS
python src/main.py --vfs scripts/vfs/minimal.csv --script scripts/startup/stage2_basic.txt
```

## Примеры использования

Интерактивный режим:

```
> python src/main.py
[debug] startup parameters:
[debug]   vfs = <not set>
[debug]   script = <not set>
user@host:~$ ls -l /tmp
ls: args = ['-l', '/tmp']
user@host:~$ foo
unknown command: foo
user@host:~$ exit
```

Стартовый скрипт `scripts/startup/stage2_errors.txt`:

```
> python src/main.py --script scripts/startup/stage2_errors.txt
[debug] startup parameters:
[debug]   vfs = <not set>
[debug]   script = scripts/startup/stage2_errors.txt
# Скрипт с ошибками: эмулятор сообщает об ошибке и продолжает работу.
user@host:~$ ls
ls: args = []
user@host:~$ foo bar
unknown command: foo
script error: line 3: command failed
user@host:~$ exit
```
