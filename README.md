# Эмулятор оболочки ОС

Консольный эмулятор UNIX-подобной командной строки на Python.
Внешние зависимости не требуются, используется только стандартная
библиотека.

## Общее описание

Проект реализует эмулятор языка оболочки ОС. На текущем этапе (этап 1,
REPL) создан минимальный прототип: эмулятор ведёт диалог с пользователем,
разбирает введённые команды и выполняет команды-заглушки.

## Описание функций и настроек

Настроек на этом этапе нет.

### Приглашение к вводу

Формируется из реальных данных ОС в виде `username@hostname:~$`.
Имя пользователя берётся через `getpass.getuser()`, имя хоста через
`socket.gethostname()`.

### Парсер

Строка ввода делится по пробелам на команду и список аргументов.
Лишние пробелы игнорируются, пустая строка пропускается.

### Команды

| Команда | Описание |
|---------|----------|
| `ls`    | Заглушка. Выводит своё имя и аргументы |
| `cd`    | Заглушка. Выводит своё имя и аргументы |
| `exit`  | Завершает работу эмулятора |

### Обработка ошибок и особых случаев

- Неизвестная команда: выводится `unknown command: <имя>`.
- Ctrl+D (конец ввода): эмулятор завершает работу.
- Ctrl+C: прерывает ввод текущей строки, появляется новое приглашение.

## Сборка и запуск тестов

Сборка не требуется. Запуск тестов:

```
python -m unittest discover -s tests
```

## Запуск

```
python src/main.py
```

Или через скрипты запуска:

```
./run.sh      # Linux / macOS
run.bat       # Windows
```

## Примеры использования

```
user@host:~$ ls -l /tmp
ls: args = ['-l', '/tmp']
user@host:~$ cd docs src
cd: args = ['docs', 'src']
user@host:~$ foo
unknown command: foo
user@host:~$ exit
```
